# Simple Web Demo 🚀

यह एक छोटा सा demo project है जो HTML, CSS और JavaScript का उपयोग करके बनाया गया है।  
इसमें एक बटन है जिसे क्लिक करने पर current time दिखाया जाता है।  

## 📂 Project Structure
- `index.html` → मुख्य HTML फाइल  
- `script.js` → JavaScript logic (बटन क्लिक करने पर समय दिखाना)  
- `style.css` → (आप styling जोड़ सकते हैं)  

## ⚡ Features
- Responsive HTML structure  
- JavaScript event handling (Button click)  
- Real-time output display  

## ▶️ How to Run
1. इस repository को download / clone करें  
2. Files को किसी भी browser (Chrome, Edge, Firefox) में open करें  
3. "Click Me" button दबाएँ और current time देखें
